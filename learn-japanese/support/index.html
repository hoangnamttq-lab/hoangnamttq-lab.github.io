Continue a lesson

Use Today to resume the paused lesson or practice session, review due cards, then follow your selected guided path. Choose Beginner, Already know kana or Intermediate in Settings. Changing your starting point keeps existing progress.

Widgets

Open Today → Set Up Lock Screen Widget or Settings → Widgets. Select a surface, size and supported mode, save the preference and follow the iOS instructions. You must add the widget yourself using iOS. “Widget configuration detected” means WidgetKit returned a matching configuration; it does not prove which Lock Screen is currently active. Use Retry or Show steps if it is not detected.

Purchases, restoration and refunds

Connect to the Internet and select Restore Purchases in Settings if an existing subscription is not verified. Use the same Apple Account. Manage renewal in Apple Account subscriptions. Request a refund through Apple at reportaproblem.apple.com. Support cannot access your Apple password or approve a refund.

Offline speech and data

Lessons and permitted local content do not require an Internet connection. Japanese voice availability depends on iOS and installed voices. Check Settings → Accessibility for the speech/voices options on your iOS version. If audio is unavailable, use the visible transcript; other learning remains available. Export progress before troubleshooting. Do not uninstall to fix a problem unless you have considered loss of local data.

Internal beta feedback

For a TestFlight build, use Send Beta Feedback in TestFlight or this support email. Report wrong readings, ambiguous answers, inaccessible controls, clipped text and widget mismatches with the lesson title or item. Internal beta coverage is not a claim of production readiness.
