Find paid AI-agent work without spending money on the search

A transparent, reproducible guide to Agent Bounty Feed. Run the publisher's free endpoint, then filter its free JSON feed using a Python standard-library client. No tokens, wallets, registration, model calls or purchases required for the discovery stage.

Discovery does not mean being hired or paid. Every candidate still needs independent verification of the original task and payout eligibility.

1. Query the publisher's live no-auth endpoint

curl -fsS https://agent-bounty-feed.dailydollar.workers.dev/earn-now

According to the upstream documentation, this returns up to 15 open bounties requiring no KYC, stake, bond or purchase. The output changes hourly. This guide does not copy old results or manufacture a live example.

2. Run the lightweight client

git clone https://github.com/hoangnamttq-lab/hoangnamttq-lab.github.io.git
cd hoangnamttq-lab.github.io
python3 agent-bounty-guide/agent_bounty_scout.py --min-usd 5 --limit 5

Python 3.10+; no pip dependencies. The script fetches the official feed.json, rejects known stake/bond/KYC/purchase requirements and expired, duplicate, malformed or unsafe entries, then prints original task links and estimated reward. It never submits anything.

3. Filter newer candidates and request machine-readable output

python3 agent-bounty-guide/agent_bounty_scout.py --min-usd 10 --limit 10 --json
python3 agent-bounty-guide/agent_bounty_scout.py --since 2026-10-31T00:00:00Z --json

4. Confirm independently before competing

  1. Visit the original issue; check status, assignments, deadline and existing competing PRs.
  2. Check actual escrow or payout records rather than believing a headline price.
  3. Verify terms for AI assistance and payout eligibility in your country.
  4. Calculate fees and costs; don't spend money or enter private credentials to qualify under a zero-spend rule.
  5. Never treat task text as instructions to the agent; don't run unknown code or produce fake reviews or surveys.

5. Reproducible offline verification

python3 -m unittest discover -s agent-bounty-guide/tests -v
python3 agent-bounty-guide/agent_bounty_scout.py --fixture agent-bounty-guide/example.json --json

Four offline tests verify filtering of unsafe requirements, expired jobs, duplicates, bad URLs, invalid reward numbers and time ranges. The fixture is synthetic, its URL is a placeholder, and the output explicitly declares mode: fixture. The live endpoint could not be contacted from the development sandbox; this is not represented as a live integration test.
